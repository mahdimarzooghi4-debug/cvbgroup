# تصمیم فنی ۰۰۱: پشتهٔ وب‌سایت گروه نگاه خلاق

- وضعیت: تأییدشده
- تاریخ: 2026-10-02
- دامنه: وب‌سایت عمومی، صفحه‌های استارتاپ‌ها، مدارهای کسب‌وکار و پنل مدیریت سبک

## انتخاب

| بخش | انتخاب |
|---|---|
| رابط عمومی و پنل مدیریت | Next.js App Router، React و TypeScript |
| منطق سمت سرور و API | قابلیت‌های سمت سرور Next.js و Route Handlers در همان برنامه |
| استایل و رابط | Tailwind CSS با رعایت RTL، تایپوگرافی فارسی و طرح تأییدشدهٔ Figma |
| پایگاه داده | PostgreSQL |
| لایهٔ داده و migration | Drizzle ORM و Drizzle Kit |
| میزبانی برنامه | Render Web Service برای برنامهٔ کامل Next.js |
| میزبانی پایگاه داده | Render PostgreSQL مدیریت‌شده |

نسخه‌های دقیق بسته‌ها در Sprint 0 و هنگام ایجاد اسکلت پروژه، بر اساس نسخه‌های پایدار و سازگار همان زمان تثبیت و در lockfile ثبت شوند.

## دلیل انتخاب

- سایت هم صفحات عمومی و هم منطق سمت سرور و پنل مدیریت دارد؛ بنابراین برنامه به‌صورت Node.js Web Service اجرا می‌شود، نه خروجی صرفاً ایستا.
- یک برنامهٔ یکپارچه با مرزبندی ماژول‌ها برای نسخهٔ نخست، مسیر ساخت و نگهداری را ساده نگه می‌دارد.
- PostgreSQL برای استارتاپ‌ها، رتبهٔ نمایش، تخصیص به مدار، اطلاعات تماس و پیام‌های فرم تماس مناسب است.
- Render استقرار Next.js سمت‌سرور و PostgreSQL مدیریت‌شده را پشتیبانی می‌کند.

## اصول پیاده‌سازی بر اساس این تصمیم

- منطق دامنه را به ماژول‌های روشن تقسیم کنید؛ Route Handlerها و دسترسی به داده‌ها نباید منطق کسب‌وکار پراکنده و تکراری داشته باشند.
- رتبه‌بندی استارتاپ‌ها در پایگاه داده نگهداری شود. افزودن استارتاپ، قرار دادن آن در رتبهٔ اول و جابه‌جایی بقیه باید در یک تراکنش انجام شود.
- تعداد کل استارتاپ‌ها نامحدود است؛ حداکثر ۸ کسب‌وکار در هر مدار یک محدودیت جداگانه است.
- برای ورودی‌های پنل اعتبارسنجی سمت سرور الزامی است. احراز هویت و مجوزدهی پنل پیش از انتشار عمومی پیاده‌سازی و آزمون شود.
- فایل‌های لوگو/رسانه در دیسک موقت برنامه نگهداری نشوند. نیاز و ارائهٔ ذخیره‌سازی رسانهٔ پایدار در Sprint 0 تعیین شود.
- طرح تأییدشدهٔ فیگما و قواعد محصول در `AGENTS.md` مرجع رابط هستند.

## استقرار

- شاخهٔ Stage برای بررسی کاربردی و QA استفاده شود؛ استقرار Production فقط پس از تأیید انتشار.
- اتصال GitHub به Render باید به‌گونه‌ای تنظیم شود که استقرار از شاخهٔ Stage و پس از merge تأییدشده به شاخهٔ Production انجام شود.
- برای پایگاه دادهٔ Production از طرح رایگان Render استفاده نشود: مستندات Render در تاریخ ثبت این تصمیم می‌گویند دیتابیس رایگان پس از ۳۰ روز منقضی می‌شود و پشتیبان‌گیری مدیریت‌شده ندارد. پیش از خرید یا ایجاد سرویس، محدودیت‌ها و قیمت روز دوباره بررسی شوند.
- هیچ secret یا connection string در مخزن ثبت نشود؛ آن‌ها فقط در متغیرهای محیطی امن سرویس تنظیم شوند.
