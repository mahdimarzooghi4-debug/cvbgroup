# پشته فنی وب‌سایت نگاه خلاق

| بخش | انتخاب |
|---|---|
| وب‌سایت و پنل | Next.js App Router، React و TypeScript |
| استایل | Tailwind CSS همراه CSS سفارشی و RTL |
| پایگاه داده | PostgreSQL با Drizzle ORM و Drizzle Kit |
| میزبانی | Render Web Service و Render PostgreSQL مدیریت‌شده |

این انتخاب برای نسخهٔ نخست یک برنامهٔ یکپارچه نگه می‌دارد و بخش عمومی و مدیریت را در کنار API و منطق سمت سرور اجرا می‌کند. فایل Figma و `AGENTS.md` مرجع محصول و رابط هستند. قبل از Production، متغیرهای محیطی، نشست مدیر، migrationها، پشتیبان‌گیری و آزمون‌ها باید آماده باشند. دیتابیس رایگان Render برای Production انتخاب نشود.
